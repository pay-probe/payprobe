How to use tables

Create a table with columns + rows, then read from it in a flow. Tables are global and injected into every run.

  • Lookup step (easiest): drag Data Tables → Table row lookup and set its Inputs — table, where_column, where_value, select_column. It returns ${{ "{" }}lookup.response.value{{ "}" }} (the selected cell), .row (whole row) and .found.
  • Whole table: reference ${{ "{" }}tables.NAME{{ "}" }} anywhere to get the list of rows.
  • Code node: context["tables"]["NAME"] gives the rows to iterate.

Example flow: lookup card_profiles by profile → feed ${{ "{" }}lookup.response.value{{ "}" }} into an auth step's pan.
